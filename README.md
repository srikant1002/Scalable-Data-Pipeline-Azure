# Scalable Data Pipeline Using Azure Data Factory and Synapse

## Overview
This project demonstrates an end-to-end scalable cloud ETL pipeline using Azure services.

## Architecture
CSV File → Azure Data Lake → Azure Data Factory → Azure Synapse → Power BI

## Technologies Used
- Azure Data Factory
- Azure Synapse Analytics
- Azure Data Lake Storage Gen2
- SQL
- Power BI

## Features
- Automated ETL Pipeline
- Trigger Automation
- Cloud Data Transformation
- Analytics Dashboard

## Workflow
1. Upload CSV file to Data Lake
2. Create pipeline in ADF
3. Load data into Synapse
4. Run SQL transformations
5. Connect Power BI

## Outcome
Successfully built a scalable cloud data engineering solution.
